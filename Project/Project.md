## Title: Shop Management

## Description: 
- This is a project named shop management. Which basically has roles: Admin, User, Vender and each role has permissions to do in this saas.
- From this platform user can buy product, vender can sell their product and admin can manage this platform totally.
- User has limited permissions only view and buy product, vender has only permission to add product, edit that product and see whether any user buy that product or not and can see only their respective income once user buy that not others.
- Admin has full access to whole saas who can manage vender also and also manage user. So, If there is any issue, problem, anything that happens admin needs to solve it.

## Roles
- Admin
- Vender
- User

## Permissions
- User Permissions
    - CRUD Profile
    - View Product list and description
    - Buy that product
- Vender Permissions
    - CRUD Product which related to them
    - CRUD profile
    - Can see their profit loss
- Admin
    - Full System access

## NOTE: Vender can be user but for this needs to login in user account. User can be vender but for selling product needs to login in vender account.

## NOTE: Admin account can only created by me.

## Feature
- Signup and login in different mode (vender, user)
- crud profile in both mode
- buy product by user and sell product by vender
